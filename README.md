# 图阅

一个多人使用的工程文档助手：通过 API 与 AI 对话，支持上传 **PDF** 和 **DWG/DXF** 文件。每个账号有自己的历史记录、自己的文件和自己的 API Key。

- 后端：Python 3.12 + FastAPI，流式输出（SSE）
- 前端：原生 HTML/CSS/JS，零构建、零外部依赖
- 账号：SQLite + scrypt 密码哈希、登录限流、按账号隔离数据
- 模型：默认 DeepSeek `deepseek-flash`，任何 OpenAI 兼容接口都能换
- 存储：**全部落在项目目录内**，复制整个文件夹就能搬走

## 快速开始

### 1. 启动

有两种方式，区别在于**服务能活多久**：

| 方式 | 表现 | 适合 |
|---|---|---|
| 双击 **`run.bat`** | 弹出一个命令行窗口，关掉窗口服务就停 | 想看运行日志、调试时 |
| 运行 **`start_server.ps1`** | **后台静默运行**，不占窗口，关掉启动它的程序也不受影响 | 日常挂着用 |

`start_server.ps1` 的用法（右键 → 使用 PowerShell 运行，或在 PowerShell 里执行）：

```powershell
powershell -ExecutionPolicy Bypass -File E:\LYT\ai-chat\start_server.ps1
```

它会先检查 8000 端口是否已被占用（避免起两份），启动后等接口真的能响应才报告成功。日志写在 `data\server.log`。

> **为什么强调这个**：如果你是在别的工具（比如编辑器、AI 助手）里间接启动服务的，那些工具退出时往往会连带清理自己拉起的子进程，网站就会突然打不开。`start_server.ps1` 用 `Start-Process` 把服务脱离出去，进程树链接断开，就不会被牵连。

启动后浏览器打开：

```
http://127.0.0.1:8000
```

### 2. 注册第一个账号

点「没有账号？用邀请码注册」，邀请码就是你自己在 `.env` 里设的 `INVITE_CODE`：

```ini
INVITE_CODE=<你设的那串字符>
```

**第一位注册的人自动成为管理员**，之后邀请码由管理后台统一生成和吊销。

### 3. 选服务商，填自己的 API Key

点右上角「设置」，**从下拉列表里选服务商**，再选模型，然后填入你自己的 Key。点「测试连通」可以当场验证。

内置的服务商：

| 服务商 | 接口地址 | 说明 |
|---|---|---|
| DeepSeek | `api.deepseek.com` | 默认，便宜，图纸识别效果好 |
| **小米 MiMo** | `api.xiaomimimo.com/v1` | 2.5 / 2.6 系列原生支持图像输入 |
| 智谱 GLM | `open.bigmodel.cn` | 国内可直连 |
| OpenAI | `api.openai.com/v1` | 需要可用的网络环境 |
| 自定义 | — | 任何 OpenAI 兼容接口，自己填地址和模型名 |

**每个人用自己的 Key，各花各的钱。**

> 模型列表里会标注哪些**不支持看图**。这个应用会把 PDF 页面和 DWG 图纸渲染成图片给模型看，选了不支持的模型，它就只能根据提取出的文字回答——图纸里画的内容它看不见。设置面板会就此给出提示。

## 让其他设备访问（Radmin VPN）

默认只监听 `127.0.0.1`，也就是只有本机能访问。要让别人用，走 Radmin VPN——服务不暴露到公网，扫描器找不到也连不上。

### 你这台机器（服务端）

1. 确认 Radmin VPN 客户端在运行，然后在命令行里查自己的虚拟地址：

   ```powershell
   (Get-NetIPAddress -AddressFamily IPv4 |
     Where-Object { $_.InterfaceAlias -like '*Radmin*' }).IPAddress
   ```

   正常情况下是 `26.` 开头的地址。

2. 双击 **`run_radmin.bat`**，**右键选择「以管理员身份运行」**（要加防火墙规则）
   它会做两件事：把 8000 端口**只**开放给 Radmin 网段 `26.0.0.0/8`，然后让服务绑定 `0.0.0.0`。
   脚本会自己探测并打印上面那个地址，不用你填。

### 其他人的设备

1. 装一个 Radmin VPN（https://www.radmin-vpn.com/），注册账号
2. 加入你的 Radmin 网络（网络名 + 密码，你把这两个告诉他们）
3. 浏览器打开 `http://<你这台机器的 Radmin 地址>:8000`

### 为什么只开放给 Radmin 网段

同一校园网或办公室网络里的人，即使扫到你这台机器的局域网地址也连不上——防火墙那条规则只放行 `26.0.0.0/8`。Radmin 的流量在隧道里是加密的，所以隧道内部用 HTTP 可以接受。

### ⚠️ 想改成公网访问的话

**必须同时做三件事**，缺一不可：

1. `.env` 里把 `COOKIE_SECURE` 改成 `true`
2. 前面套一层 HTTPS（Caddy、nginx + Let's Encrypt、Cloudflare Tunnel 都行）
3. 重新审视下面的「安全说明」——公网暴露后风险等级完全不同

### 校园网能不能连通？

Radmin 靠双方主动外连到它的协调服务器工作，不依赖校园网内的设备互访，所以**校园网的客户端隔离通常不影响它**。但如果学校主动识别并限制 VPN 协议，可能连不上或很慢。

真的遇到这种情况，备选是 Tailscale——它同样走中转，但**支持自建国内中转节点**，可以绕开跨境线路（Radmin 的协调服务器在海外，实测指向法国 OVH）。

## 账号与权限

| 角色 | 能做什么 |
|---|---|
| **管理员**（首位注册者） | 上面全部，外加管理后台：建账号、改密码、停用/删除账号、生成邀请码、查看审计日志和使用统计 |
| **普通用户** | 只能看到自己的对话和文件；知道别人的 conversation_id 也读不到 |

**隐私边界**：管理员能看到账号信息、用量和操作日志，**但看不到别人对话的内容**——后台不提供查看消息的功能。作为机器所有者你当然能翻文件，但界面不给这个口子。

**护栏**：最后一个管理员不能停用或删除自己。

**邀请码**：可设有效期和可用次数，可单独吊销。已经用过的账号不受吊销影响。

`.env` 里那个引导码**不限使用次数**——它是你自己的码，用完就进不去只是添堵，而真正的门禁是"别把它告诉别人"。在管理后台生成新码时可以勾「不限次数」，也可以填具体次数（用完自动失效）。

> 如果你希望这台实例**只有你一个账号**，那就别把邀请码发给任何人。需要更硬的限制（比如直接封顶账号总数）告诉我，可以加。

**忘记密码**：让管理员在后台点「改密码」，会同时让该账号所有登录失效。

## 关于 DWG：装一个转换器，体验完全不同

DWG 是 Autodesk 的私有二进制格式，Python 生态里**没有**能直接读它的库。所以本项目走这条路：

```
DWG ──[ODA File Converter]──> DXF ──[ezdxf]──> 文字/图层/块 → 交给 AI
                                    └────────> 渲染成图片 → 交给 AI 看图
```

**不装转换器也能用**，但会退化成"降级模式"：只能抠出 DWG 文件头里内嵌的预览缩略图，分辨率低、读不到文字标注。

### 安装 ODA File Converter（免费，约 10 分钟）

1. 打开 https://www.opendesign.com/guestfiles/oda_file_converter
2. 免费注册一个账号（只需要邮箱）
3. 下载 Windows 版并安装，默认路径类似 `C:\Program Files\ODA\ODAFileConverter 25.4.0\`
4. **重启本服务**，左下角状态栏变成绿色的「ODA 转换器已就绪」即成功

装到了非默认路径？在 `.env` 里指定：

```ini
ODA_CONVERTER_PATH=D:\Tools\ODA\ODAFileConverter 25.4.0\ODAFileConverter.exe
```

## 文件是怎么处理的

| 类型 | 处理方式 |
|---|---|
| **PDF** | 先用 PyMuPDF 提取文字层。逐页判断：文字够读就只发文字，是扫描件或 CAD 出图就把页面渲染成图片交给视觉模型。 |
| **DWG** | 经 ODA 转 DXF，用 ezdxf 提取图层名、文字标注、块引用、尺寸标注，同时渲染整张图纸为图片。 |
| **DXF** | 跳过转换，直接解析。 |
| **PNG/JPG** | 压缩后直接交给视觉模型（也支持直接从剪贴板粘贴截图）。 |
| **TXT/MD/CSV** | 按 UTF-8/GBK 依次尝试解码后作为文本上下文。 |

### 上下文预算

图片是以 base64 内联进请求的，而 DeepSeek 的请求体上限是 **48 MiB**，所以做了两道限制：

- 每张图压到长边 ≤ `IMAGE_MAX_PX`（默认 1800px）的 JPEG
- 单轮最多带 `MAX_IMAGES_PER_TURN`（默认 6 张）张图，**从最新的一轮往前分配**

真撞上限时不会静默丢内容，聊天里会明确提示。如果提问涉及很后面的页面，更省的做法是单独上传那几页。

### 右侧数据面板

识图完成后，右侧会自动展开一个面板（默认半个窗口，**宽度可以拖**）：

- 拖动聊天区和面板之间的**竖条**调整宽度（鼠标移上去会变蓝）
- **双击那条竖条**复位成半个窗口
- 宽度会记住，下次打开还是你调过的尺寸

宽度有上下限：面板最窄 320px，聊天区至少保留 420px。空间紧张时顶部会自动隐藏用户名，避免按钮折成竖排。

面板内容：

- **上半**：图纸的渲染图，多张图纸时下面有文件名按钮可以切换
- **下半**：模型从图里提取出的数据表

表格的每一列都能点击排序：**类别 / 项目 / 数值 / 单位 / 原始标注 / 备注 / 来源**。

数值列是**按数字大小排的，不是按字符串**——否则「100」会排在「40」前面，对图纸尺寸毫无意义。**没有数值的行（比如技术要求）无论升序降序都固定沉在底部**，不会在你切换方向时翻上来打乱视线。

顶部有个筛选框，输入「镀镍」「尺寸」「40」都能即时收敛。关掉面板后，点顶部工具栏的「数据」可以重新打开。

**识别结果会保存下来**，刷新页面不会丢：

- 关掉浏览器再打开，上次的对话和右侧数据表会自动恢复
- 就算没恢复对话，点「数据」也能拿回最近一次的结果
- 数据跟着对话走——打开哪个对话，面板就显示那次的数据；把对话删掉，数据也一并清掉

存的位置是 `data/users/<你的账号id>/extractions/<对话id>.json`，和对话记录放在一起。

代价要说清楚：**这一步会额外调用一次模型**，而且因为图纸是以图片形式送过去的，那次的图片会被重复发送。上传的图纸越多，这一次越慢。不想要的话告诉我，可以改成手动点按钮触发。

### 中文图纸渲染成方框？

程序会自动检测图纸里的中文标注，并把文本样式指向系统中文字体（优先 `simhei.ttf`）再渲染。看不到方框就不用管这件事。

原理：AutoCAD 的 SHX 字体（`txt`、`simplex` 这些）在 ezdxf 里会解析到 Arial，而 Arial 没有中文字形。**文字提取不受影响**，方框只影响渲染出的那张图。系统里没有中文字体时，可以在 `.env` 里指定：

```ini
DRAWING_CJK_FONT=C:\Windows\Fonts\simhei.ttf
```

整个项目是自包含的——运行时的缓存和临时文件都被重定向进了项目目录，不会散落到 C 盘用户目录。


## 数据安全：账号不会因为改代码而丢失

`data/` 里是真实的东西——账号、密码哈希、每个人的 API Key、对话、上传的图纸。**这里没有可以重新生成的内容**，所以有两条硬规矩：

### 改表结构用迁移，不重建

`app/accounts.py` 里的 `_REQUIRED_COLUMNS` 是加字段的地方：

```python
_REQUIRED_COLUMNS = {
    "users": {
        "email": "ALTER TABLE users ADD COLUMN email TEXT NOT NULL DEFAULT ''",
    },
}
```

登记到那里，`init_db()` 启动时会用 `ALTER TABLE` 就地补上，**老数据库平滑升级，账号一个不少**。这个机制只增不减——想删字段或改类型，必须先备份并征得同意。

有测试专门守着这条规矩：

```bash
.venv\Scripts\python.exe scripts\migrationtest.py
```

它会造一个旧版本的数据库（缺字段、含账号），跑一次升级，然后逐项核对用户名、密码哈希、管理员身份、以及旧的多余列都没有被动过。

### 动数据之前先备份

```bash
.venv\Scripts\python.exe scripts\backup.py
```

打包 `accounts.db` 和所有人的数据到 `backups\` 下带时间戳的 zip。备份**刻意放在 `data\` 外面**——否则清理数据目录会连备份一起毁掉。备份不会被自动删除，你自己定期清理。

> 备份里包含所有人的密码哈希和加密后的 API Key，请妥善保管，别随手丢到网盘或者发给别人。

### 想看当前有哪些账号

```bash
.venv\Scripts\python.exe scripts\status.py
```

只读，不动数据。改动前后各跑一次，心里有底。

### 想调试又不碰真实数据

用 `YUE_DATA_DIR` 指向临时目录，起一个完全隔离的实例：

```bat
set YUE_DATA_DIR=%TEMP%\yue_scratch
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8001
```

`scripts\migrationtest.py` 就是这么做的，可以照抄。

### 测试脚本不会占用你的邀请码

`authtest.py` / `httptest.py` / `livetest.py` 会自己生成一个备注为「自动化测试专用」的邀请码来注册临时账号，用完就删，**不消耗你在 .env 里配的引导码**。不想留着的话，在管理后台吊销它即可。

## 自测

改完代码想确认没搞坏东西，按这个顺序跑：

```bash
.venv\Scripts\python.exe scripts\selftest.py    # 解析链路，不花钱
.venv\Scripts\python.exe scripts\authtest.py    # 账号与权限，需服务在运行
.venv\Scripts\python.exe scripts\migrationtest.py  # 数据迁移，隔离运行
.venv\Scripts\python.exe scripts\httptest.py    # HTTP 接口，需服务在运行
.venv\Scripts\python.exe scripts\checkkey.py    # 只验 Key 能不能通
.venv\Scripts\python.exe scripts\livetest.py    # 真实问答，会消耗 API 额度
```

- **selftest.py** 造一份 DXF、一份文字型 PDF、一份扫描型 PDF，检查文字提取、图纸渲染、扫描件转图三条路径。
- **authtest.py** 覆盖注册、会话、**跨用户隔离**、邀请码、限流、路径穿越、管理员权限。需要数据库里还没有账号才能测管理员部分（首位注册者才可能是管理员），否则会跳过并说明。
- **migrationtest.py** 在临时目录里造一个旧版本的数据库（缺字段、含账号），跑一次升级，逐项核对用户名、密码哈希、管理员身份都没被动过。**它不碰你的真实数据。**
- **httptest.py** / **livetest.py** 会自动创建一个临时账号跑测试，结束后删掉。也可以用 `YUE_TEST_USER` / `YUE_TEST_PASSWORD` 指定自己的账号。
- **livetest.py** 最有价值：它在文件里埋入确定的事实（比如"三层层高 4.2 米"），上传后提问，再检查模型答对没有。只有它能证明模型真的读懂了文件。

## 安全说明

### 已经做的

- 密码用 scrypt 加盐哈希，比对用常数时间函数，不泄露账号是否存在
- 会话 token 只在数据库里存 SHA-256 哈希；Cookie 是 `HttpOnly` + `SameSite=Strict`
- 登录和注册都限流（同 IP + 用户名 15 分钟 5 次）
- 所有人的对话和文件按账号分目录隔离，路径经过严格校验
- 每个人的 API Key 加密存储
- 登录限流分两层：同一个账号 15 分钟错 5 次锁定；同一个来源地址 15 分钟错 20 次也会被拦，防止有人换着用户名试
- CSP、`X-Frame-Options: DENY` 等安全响应头
- 上传上限 50 MB

### 你必须要知道的剩余风险

1. **上传的文件会被 PyMuPDF、ezdxf、ODA File Converter 解析。** 这些是复杂的 C/C++ 解析器，构造恶意文件理论上可能攻破它们。**这是整个系统最大的风险点。** 邀请码挡得住陌生人，挡不住拿到账号的人的恶意文件。真正的解法是把程序关进虚拟机隔离——那是另一个量级的工程。**建议只给自己和完全信任的人开账号。**
2. **Radmin 无法按设备限制端口。** 加入你 Radmin 网络的人能访问这台机器的**所有**端口，不只是 8000。别往同一个网络里放不认识的人。
3. **服务端能看到使用者的 API Key。** 加密防的是备份泄露和随手翻文件，**防不了拿到整台机器的人**。建议大家都用设了消费上限的 Key。
4. **Radmin 是闭源工具**，协调服务器在海外，隧道内容它声称加密但无法独立验证。
5. **管理员后台是高风险面。** 它能重置任意密码，等于万能钥匙。务必给管理员账号用强密码。
6. **登录只有密码一道关。** 邮箱验证码功能已按你的要求移除，所以密码是唯一的凭证。防住暴力破解靠的是限流（同一账号 5 次、同一地址 20 次锁定），但**防不住"你在别处用了同一个密码被拖库"**——那种情况下没有任何机制能拦。请给这个账号用独立密码。
7. 加密和限流能挡住绝大多数攻击，但**没有任何系统是"绝对"安全的**。

## 换模型 / 改名字

改 `.env` 重启即可，代码不用动：

```ini
APP_NAME=图阅
AI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
AI_MODEL=glm-5.3
```

`APP_NAME` 会出现在侧栏标题、浏览器标签页和回答旁的头像上（头像取名字第一个字）。

注意：**要读图纸就必须用支持图片输入的模型**，纯文本模型会忽略渲染出来的图。每个用户也可以在「设置」里覆盖自己的接口地址和模型。
